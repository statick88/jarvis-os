# Discovered by scanning every top-level (unguarded) import in jarvis_os/**.py
# and resolving each module to its installed distribution version. There was no
# dependency declaration in this repository before, which is why an environment
# could not even import jarvis_os.floci_client.
#
# Install:  pip install -r requirements.txt

# protobuf note: jarvis_os/voice_bridge/gen/voice_api_pb2.py is generated code
# that calls ValidateProtobufRuntimeVersion(..., 7, 35, 1, ...). It REQUIRES a
# protobuf runtime >= 7.35.1. A runtime older than that raises
# protobuf.runtime_version.VersionError at import. This constraint reflects the
# committed gencode, not a preference. If your environment has an older
# protobuf, either upgrade it or regenerate the stubs from
# spec/contracts/voice_api.proto with a matching protoc.
